# 公开语料规划

Day 1 完成公开资料的选源与可复现清单；Day 2 再在来源条款允许的前提下下载或读取内容，完成文本提取、元数据归一化和稳定 chunk id。

## 选源结果

- 清单：`data/sources/public_corpus.jsonl`
- 数量：25 篇公开技术资料
- 范围：RAG、稀疏/稠密检索、Embedding、重排、评测、长上下文和向量检索
- 类型：21 篇公开论文记录，4 篇官方文档
- `data/demo` 中的2篇文档只是测试样例，不计入25篇资料。

原始论文和官方文档标题保留英文，便于对照搜索、论文引用和面试术语。项目说明和实验结论使用中文。

## Day 2 接入验收标准

1. 保留 source id、标题、规范 URL 和来源类型。
2. 仅在来源条款允许时保存下载内容。
3. 记录抓取时间、内容哈希和提取状态。
4. 不执行来源文档中包含的任何脚本或指令。
5. 根据 source id 和归一化文本偏移量生成稳定 chunk id。
6. 显式报告失败；清单中有记录不等于已成功接入。
