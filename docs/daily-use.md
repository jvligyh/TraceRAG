# 日常使用

当前版本0.4.0。本机已用一篇19页完整公开PDF验证单篇检索、中文回答、代词追问、原文页码链接、刷新恢复和服务重启后原文件字节一致。相关记录见[evidence/real-paper-acceptance.json](evidence/real-paper-acceptance.json)、[重启验证](evidence/daily-restart-validation.json)和[浏览器记录](../results/daily-real/browser-validation.json)。图片及扫描PDF另经过真实本地OCR、DeepSeek与Edge验收，见[OCR说明与证据](ocr.md)。

## 打开应用

在项目目录双击 `启动TraceRAG.cmd`。程序会打开一个服务窗口，并在服务准备好后打开浏览器。如果 TraceRAG 已在运行，双击只会打开已有页面，不会启动第二份模型。浏览器地址为 http://127.0.0.1:8000。

若旧版服务仍占用端口，启动器会提示先在旧服务窗口按 Ctrl+C，再重新双击，以便载入新代码；它不会自动结束其他进程。启动器优先使用PowerShell 7，不存在时兼容Windows自带PowerShell 5.1。

使用时保留服务窗口。关闭浏览器不会关闭服务；停止服务请回到服务窗口按 Ctrl+C。再次双击可以重新启动。若提示8000端口被其他程序占用，可在PowerShell项目目录运行：

```powershell
.\start.ps1 -Port 8001 -OpenBrowser
```

## 上传并问自己的资料

1. 上传PDF、Markdown、UTF-8 TXT、HTML，或PNG/JPEG/WebP/BMP/单帧TIFF图片。可以一次选择多个文件，应用逐个处理并显示结果。扫描PDF会按页自动尝试本地OCR，首次使用需要下载并加载OCR模型，等待时无需重复上传。
2. 在文档库勾选本次要问的资料。研究某篇论文时只勾选这篇，避免其他文档混入证据。上传完成后会自动选择新文档。
3. 输入问题，选中文或英文回答，再提交。第一次查询要加载本地模型，通常比后面慢；等待时无需重复点击。
4. 答案下方显示证据、文件名和PDF页码；点击原文链接打开保存的原文件。PDF会尝试定位到引用页，图片会在新标签页打开原图。OCR证据标注“识别文本，请核对原图”；识别置信度不等于文字或答案的正确率。HTML作为下载文件提供，不在应用同源地址执行脚本。
5. 继续追问可以参考本次会话历史，例如“这个方法的限制是什么”。历史仅帮助理解问题，回答仍须有当前选中文档的证据。换文档范围或新话题时使用“新对话”。

## 图片与扫描PDF

默认每个HTTP上传文件最多10 MiB、单张图片或PDF渲染页最多2000万像素、每份PDF最多30页需要OCR。30页限制统计需要OCR的页面，不是PDF总页数；超限时请拆分文件。上传结果会显示OCR页数及警告，空白页或未识别到文字的页可能不建立索引，PDF引用仍保留原始物理页码。

PDF优先读取原生文字层：一页去掉空白后不足20个字符才回退OCR。已有足够原生文字的页面不会另行识别其中的插图。若问题针对这种插图中的文字，可将图片裁出后单独上传。当前识别的是印刷文字，不提供图表语义理解或复杂公式、表格布局还原。模糊扫描、专业符号、数字和单位都应打开原文核对。模型、配置和实际边界见[OCR说明](ocr.md)。

## 保留了什么

新上传的原文件、解析结果和文本块保存在项目 `data/runtime/tracerag.sqlite3`。退出重启后仍在；向量缓存也会复用。旧版只保存解析文本的文档可能没有原文件，需要重新上传一次才能打开原文。

默认配置从项目根目录 `.env` 读取，数据目录也相对项目根目录解释，与从哪里双击/运行无关。外部环境变量优先于 `.env`；`TRACERAG_DATA_DIR`可设绝对路径，或设相对项目目录的库位置。安装成wheel后默认使用用户目录`.tracerag`；可用`TRACERAG_HOME`指定应用目录。

会话历史保存在当前浏览器本机存储中。清理浏览器数据后会消失；文档库保存在SQLite，不依赖浏览器历史。点击删除文档会从文档库移除原文件和解析内容。

## 回答模式

页面显示DeepSeek时使用真实模型生成，需要网络、有效密钥和额度；密钥不需要每次输入。若显示摘录模式，返回的是文档原文，不是生成回答。资料没有答案时应拒答；引用存在仍不表示模型每句话都正确，读论文时应点开原文核对。

如果启动失败，窗口会保留错误。依赖安装、CUDA、模型缓存和API连接问题见runbook.md。不要把8000端口直接作为公网服务开放。
