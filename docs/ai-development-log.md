# AI 协作开发记录

## 2026-10-29：0.4.0 本地OCR

AI接入RapidOCR与扫描PDF逐页回退，增加图片上传、原图预览、OCR来源/置信度传递及失败提示；保留原有检索与回答接口。采用程序生成的中英印刷文字图片和扫描PDF做真实模型、HTTP、浏览器及重启验证，空白页跳过且物理页码不变；157项测试通过。验收记录在`docs/evidence/ocr-live-validation.json`、`ocr-restart-validation.json`和`results/ocr-browser/`。这些合成样例只能证明链路可用，不能代表真实论文、手写或拍照场景的识别准确率。

建议人工学习顺序：`ocr.py`看模型输入输出 → `ingestion.py`看何时OCR → `schemas.py`/`chunking.py`看识别来源如何传递 → `test_ocr_ingestion.py`看混合PDF与空白页测试；再上传本人材料核对数字和专业词。此处建议尚不代表用户已完成。

本文档记录 AI 产出如何被人工理解和验证，而不是将代码直接接受。

## 2026-09-13：Day 1 骨架

### 目标

建立一个无需凭据即可测试的项目边界，以后可接入华为 MaaS、本地模型或其他供应商，同时不将检索逻辑绑定到某个 API。

### AI 贡献

- 提出初始仓库结构；
- 起草 Provider Protocol、确定性 Mock 和最小 Pipeline；
- 起草单元测试与项目文档；
- 整理25篇公开技术资料清单。

### 必须由人完成的验证

- 能独立解释每个公开类和方法；
- 在本地亲手运行全部测试；
- 独立完成一次代码修改；
- 确认架构与华为 AI 应用岗位匹配；
- 拒绝任何没有实测证据支撑的简历表述。

### 证据

- 冒烟脚本输出；
- `unittest` 输出；
- 人工修改的 `git diff`。
